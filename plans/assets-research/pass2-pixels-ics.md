## Notes on sources

- **LCSC direct files.** LCSC's viewer page (`www.lcsc.com/datasheet/C….pdf`) embeds the real file as
  `https://datasheet.lcsc.com/datasheet/pdf/<md5>.pdf`, which serves `application/pdf` to bots. That's
  the same form the first-pass pixels report used for sk6812 and ws2816.
- **Titan Micro.** The TM1804 product page now links V2.3 through
  `/index/article/download.html?file=<base64>&name=TM1804_V2.3`. It returns the PDF **only with a
  `titanmec.com` Referer**. Without one (as the mirror fetches), it returns a 439-byte 404 page, and the
  decoded direct path `/upload/twdz_cn/…pdf` redirects to a 404 too. So it can't be a `url`, but the
  first pass's "download link broken" is really "Referer-gated". No Wayback capture exists.
- **WorldSemi.** The redesigned site now has package images (`/assets/products/ws2808-sop8.webp`,
  `ws2818b-sop8.webp`, `ws2811-sop8.webp`, `ws2801-sop14.webp`, `ws2805-sop10.webp`, …). They're templated
  renders: the same SOP-8 picture with only the typeset marking changed. Skipped per the precedent that
  pixel ICs get an image only for a real photo of that chip.
- **Sunmoon.** Its detail pages (e.g. detail_128 SM16704PB, detail_140 SM16824E) show pinout drawings, and the
  SM16726 page (detail_118) has no image or PDF.
- **Greeled** (gree-leds.com) shows real photos of its own parts: GE1603R chip, GE8812 LED.
