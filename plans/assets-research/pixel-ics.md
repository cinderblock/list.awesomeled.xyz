# Assets report: pixel-ics

Batch `pixel-ics` (41 entries). Datasheets first, then images.
Final checks: `bun run mirror-datasheets --check --only pixel-ics` → **34 ok, 0 failing**;
`bun run validate pixel-ics` → 41/41 valid; `bunx eslint database/pixel-ics` clean;
prettier clean. Every alternate `sources` URL was also checked separately (54/54 are real PDFs).

Notes on sources:

- **Maker sites.** Worldsemi PDFs live at `world-semi.com/web/userfiles/productfile/…`. The redesigned
  site's own "Download Datasheet" buttons are `#` placeholders. Sunmoon (chinaasic.com) links its PDFs
  from chip detail pages. MY-Semi works over plain http only, because its https certificate is for a
  different host. Titan Micro's (titanmec.com) download endpoint returns a 404 page (as
  `application/octet-stream`) for every TM18xx part. UCS (深圳联芯科微电子, szucs.cn) publishes no
  PDFs at all. Macroblock gates its datasheets behind its download area.
- **Community copies.** Where the maker has no live PDF, I used copies from LED-strip vendors that
  host the original documents: LEDYi's "Addressable/Pixel IC Datasheet Hub" (media.ledyi.com, plus the
  older wp-content path) and Superlighting LED (`superlightingled.com/PDF/…`). The `url:` line
  carries a YAML comment naming who hosts the copy and which revision it is.
- **Copies I rejected.** Lumikit's copies of Titan datasheets start with a UTF-8 BOM before `%PDF`, so
  they fail the magic check (TM1914 is the exception). LCSC and Mouser serve HTML to bots.
