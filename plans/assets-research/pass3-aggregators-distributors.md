# Pass 3: maker-first datasheets, aggregator / distributor / forum batch

Done 2026-11-27 4:43 PM PST (00:43Z). 17 entries; nothing committed or staged. Four files changed:
`database/pixel-ics/{dm412,ws2808,ws2821}.yaml` and `database/pixels/ws2816.yaml`. Every entry passes
`bun run mirror-datasheets --check --only <entry>`. `bun run validate` reports 609/609 valid, and eslint
and prettier are clean on the changed files. The Internet Archive kept going offline during the run, so
Wayback-first entries (dm412, ws2821) sometimes passed through their fallbacks. When the Archive was up,
each Wayback URL served `application/pdf` with `%PDF-`.

Notes on makers:

- **WorldSemi.** Each product page on the new site (`/products/<part>.html`, listed in `/sitemap.xml`)
  carries a real datasheet link, `/downloads/datasheets/{en,zh-CN}/<part>-<ver>.pdf`. The catalog pages
  only show `#` placeholders. The old `/web/userfiles/productfile/` files still serve live (e.g. the
  WS2816 family). The 2013–2016 site's `/uploads/soft/<yymmdd>/…pdf` files survive only in Wayback.
  WS2816, WS2821 and WS2822S aren't on the new site (WS2816 is now sold as WS2916).
- **Opsco** (opscoled.com). Its download page is a form that asks for name, phone and company before
  it hands out a file. I didn't submit it (no personal details). Its list has SK6812 but not SK6851 or
  SK6818. Wayback has no Opsco files.
- **Macroblock.** Its download area holds only articles and certificates. The page says "For the latest
  product datasheets, please email to marketing@mblock.com.tw". Wayback holds only 2004-era PDFs.
- **Sunmoon** (chinaasic.com). Its chip-list API (`/product/selectChipList`, pifId 29/30) returns 40
  parts and no SM16711. Wayback has no chinaasic.com URL containing "16711".
- **UCS** (szucs.cn). No PDFs, downloads or Wayback captures (as in passes 1 and 2).
- **Silicon Touch** (siti.com.tw). The site doesn't answer: DNS resolves, but connections time out.
  Wayback holds `product/spec/LED/SP-DM412-A.003.pdf` and `A.004.pdf`.
- **LDT** (ldt.co.kr). The LED Driver IC page lists LD1510 as "Mass Production" but has no datasheet or
  download. Wayback has nothing for ldt.co.kr.
- **Greeled** (gree-leds.com). Its download area (7 pages, ~80 files) has no INK1002 or INK1003. Wayback
  has no Greeled PDFs.
- **LCSC search** (`wmsc.lcsc.com`) returns 403 to scripts, so I couldn't look for distributor copies
  there. Web searches found no LCSC or szlcsc copy for SM16711, UCS1909, UCS6909 or LD1510.

## Suspected data errors

- **pixel-ics/ws2808.** WorldSemi's own Chinese V1.2 (revision log: "V1.2 更新logo；增加应用电路 20260716")
  lists **SOP8 and SOT23-8** packages. V1.0 and V1.1 (and the entry's `physical.packages` and second
  `discrepancies` line) say SOP8 and FSOP8. The szlcsc "V1.2" is a different file: titled WS2808F,
  dated 2025-12-02, still SOP8/FSOP8. So the `technical_notes` line calling the szlcsc file "WorldSemi's
  V1.2 datasheet" is out of date. Spec fields not edited.
- **pixel-ics/ws2821.** The two maker revisions disagree on quiescent current: 1.5 mA (REXT 500R) / 3.0 mA
  in the 2014-03 file versus 3 / 4.5 mA in the 2014-06 file. The entry has no `quiescent_current`, so
  nothing to fix; noted in the `sources` entry.
- **pixel-ics/ld1510.** The maker lists the part as "Mass Production", but the entry has no `status`.
- **pixels/sk6818.** The url is a Conrad LED **strip** datasheet, not a part datasheet (already noted in
  pass 1).
