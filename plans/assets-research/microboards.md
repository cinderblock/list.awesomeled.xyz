## Tooling issues seen (not fixed; outside batch scope)

- **mirror-datasheets from Git Bash on Windows.** Bun's fetch fails TLS (EPROTO) against raspberrypi.com hosts. The curl fallback then resolves to Git's mingw curl 8.8.0, which exits 43 on `-L` redirects combined with `-w '%{http_code}'`. Result: all 10 `datasheets.raspberrypi.com` links FAIL from Git Bash but are ok from PowerShell, where System32 curl 8.22 is used. CI on Linux is likely unaffected.
- **Shopify stores were returning `429 local_rate_limited`** (store.arduino.cc, lilygo.cc). I worked around it with Wayback page captures plus direct cdn.shopify.com image URLs.
